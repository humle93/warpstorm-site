# warpstorm-site

Versionstyring for **Warpstorm** (Warhammer 40K-projektet, grimdarkbuilds.com / warpstorm). WP-kernen ligger på Hostinger — repoet holder planer, artikler og design-assets.

## Struktur
- `articles/` — klargjorte artikler (skabelon: H1 → kort svar → disclosure → tabel → guide → billeder → FAQ → interne links → CTA).
- `docs/warpstorm-grimdark-plan.md` — komplet WordPress-pakke (TT5, plugins, kategorier, CSS-vars, 34 artikler, monetisering).
- `docs/kickoff-drejebog.md` — drejebog fase 0-2.
- `docs/` ellers: statusnoter pr. artikel.

## Bindinger (IP-regel)
- Uofficiel fanside: guides/lore/cosplay er OK.
- Shop: ALDRIG Games Workshop-navne eller logoer — kun generiske produktnavne ("Inquisitor Coat" osv.).
- rel="sponsored nofollow" på affiliate-links.

## Noter
- Repoet oprettes og opdateres via GitHub API; ingen lokal git-CLI i Juno-workspace.
